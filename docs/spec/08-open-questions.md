## 3. 결정 완료 (2026-10-01, v0.4)

| 구분 | 결정 | 구현 해석 | 반영 위치 |
|---|---|---|---|
| 인증 보상 | 병더리움 1개 → 현금 250,000원(시드의 1/4) | 다음 운영일 09:00에 현금잔고로 지급(지급 시점·대상 규칙은 v0.3과 같음). 관리자 파라미터 `reward_cash` | [05 §3](05-certification.md#3-보상-지급-필수), [02](02-parameters.md) |
| 코인 초반 변동 | 초반 3~4일은 너무 크게 움직이지 않게 | 1~3회차(10/7~10/9 시작가) 하루 변동폭 -10%~+30%, 4회차부터 평소 -40%~+200%. 회차 수는 `coin_calm_rounds`로 조정(4면 10/10 시작가까지) | [03 §1.5](03-pricing.md#15-초반-안정기-v04) |
| 코인 평소 변동폭 | 안정기가 아닐 때도 10회 누적 20배 초과 확률 1% 미만 | 평소 하루 변동폭 -50%~+300% → -40%~+200%. 상승 확률 30%와 X³·X² 모양은 그대로, 로그 기대값 0 근처(약 -0.004). 20배 초과 약 2.0% → 0.45%(안정기 포함 0.15%) | [03 §1](03-pricing.md#1-병더리움코인-가격-산정), [02](02-parameters.md) |
| 수익률 | 참가자별 수익률 표시. 처음 시드와 공부 인증으로 받은 시드를 합한 금액에서 얼마를 벌고 잃었는지로 계산 | 수익률 = (총자산 − 투입 원금) ÷ 투입 원금, 투입 원금 = 시드 + 받은 인증 보상. 랭킹(수익률 순 보기)·내 자산·관리자 참가자 목록에 표시 | [07 F-10](07-requirements.md), [05 §3](05-certification.md#3-보상-지급-필수) |
