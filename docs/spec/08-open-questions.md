# 미결정 항목 (개발 착수 전 결정)

아래 항목은 현재 규격에 확정되어 있지 않다. 권장안은 이벤트 목적(공부 인증 지속)과 구현 난이도를 함께 고려한 기본값 제안이다.

체크박스는 결정 완료 여부를 표시한다. 결정 시 **결정** 란에 확정값과 일자를 기록하고, 관련 규격 파일을 갱신한다. 원문에서 이미 "확정"으로 표기된 항목은 체크되어 있다.
