# 기능 요구사항 (개발팀 전달용)

| ID | 기능 | 상세 | 우선순위 |
|---|---|---|---|
| F-01 | 참가자 등록 | 참가 신청 처리, 초기 현금 1,000,000원 지급, 1인 1계정 검증. 중도 참가 허용(시드 동일) | 필수 |
| F-02 | 시세 조회 | 5종목 현재가·전일 대비 변동률·가격 이력(일별) 제공 | 필수 |
| F-03 | 매수·매도 주문 | 09:00–18:00 접수, 수량 입력, 당일 시작가로 즉시 체결, 잔고·보유수량 검증 | 필수 |
| F-04 | 포트폴리오 | 보유 현금, 종목별 수량·평균단가·평가손익, 총자산, 투입 원금(시드 + 받은 인증 보상)·수익률 표시 | 필수 |
| F-05 | 일일 정산 배치 | 18:00 실행 — 종목별 매수 집계→주식 변동률 산출, 코인 변동률 추출(30:70 2단 분포, 초반 안정기 회차는 좁은 변동폭), 다음 운영일 시작가 확정 | 필수 |
| F-06 | 공부 인증 제출 | 인증 자료 업로드, 1일 1회 제한, 마감 시각 검증 | 필수 |
| F-07 | 인증 검수 | 관리자 승인/반려, 반려 사유 기록 | 필수 |
| F-08 | 보상 지급 배치 | 승인된 인증에 대해 다음 운영일 09:00 현금 고정 금액(기본 250,000원, 시드의 1/4) 지급(v0.4) | 필수 |
| F-09 | 거래·정산 로그 | 주문/체결/정산/지급 전체 이력 보관(분쟁 및 감사 대응) | 필수 |
| F-10 | 랭킹 | 총자산 기준 순위, 참가자별 수익률(투입 원금 기준)·수익률 순위(v0.4), 인증 연속일수 표시. 시상 순위는 총자산 100% 기준(v0.3), 닉네임만 공개 | 권장 |
| F-11 | 관리자 백오피스 | 파라미터(코인 상승 확률·상승폭 지수·하락폭 지수·일일 상하한·초반 안정기, 주식 감도 계수·매수지분 잡음, 뉴스 확률·효과 범위, 가격 하한, 인증 보상액) 조정, 수동 가격 개입, 호재·악재 작성, 참가자 관리 | 권장 |
| F-12 | 알림 | 장 시작·마감, 정산 결과, 인증 리마인더 푸시 | 선택 |
| F-14 | 호재·악재 | 운영일 09:00 공시와 함께 주식 뉴스 발표, 18:00 정산에서 쏠림 변동률에 곱으로 반영. 전날 정산 때 무작위 생성(확률·효과 범위 파라미터) + 관리자 직접 작성·삭제. 참가자 시세판·종목 화면·뉴스 카드에 표시 | 권장 |
| F-13 | 정산 시뮬레이터 | 현재 파라미터(초반 안정기 포함)로 10회 가격 경로를 반복 생성해 분포·순위 분산 확인(파라미터 확정 및 사전 검증용) | 권장 |

관련 규격: [03-pricing.md](03-pricing.md) (F-05, F-13, F-14), [04-trading.md](04-trading.md) (F-03, F-05), [05-certification.md](05-certification.md) (F-06 ~ F-08), [02-parameters.md](02-parameters.md) (F-11).
