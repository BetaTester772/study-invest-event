# 데이터 모델

아래 필드는 [기능 요구사항](07-requirements.md)에서 요구하는 화면·처리를 지원하기 위한 최소 정의다. 타입·키·인덱스 등 물리 설계는 구현 재량이다.

## 1. 종목 마스터 (Instrument)

모든 참가자는 동일한 초기 조건으로 시작한다. 아래 시작가는 이벤트 1일차 장 시작 시점의 가격이다.

| 구분 | 종목명 | 약칭 | 시작가 | 성격 |
|---|---|---|---|---|
| 주식 | 삼수전자 | SAMSU | 75,000원 | 대형주 |
| 주식 | SK로우닉스 | SKLOW | 170,000원 | 고가 대형주 |
| 주식 | 미래대 | MIRAE DAI | 40,000원 | 중형주 |
| 주식 | LB | Life is Bad | 14,000원 | 저가주 |
| 코인 | 병더리움 | BYUNG | 250,000원 | 고변동 투기 자산 |

## 2. 주요 엔티티

### 참가자 (Participant)

| 필드 | 설명 · 제약 |
|---|---|
| 참가자ID | 내부 고유 식별자. |
| 식별자 | 1인 1계정 검증용(사내 계정·학번·전화번호 등). [다중 계정](06-abuse-risk.md#2-다중-계정) 참조. |
| 현금잔고 | 보유 원화. 초기값 1,000,000원(중도 참가자도 동일). 매수 시 차감, 매도 시 증가. 이자 없음. |
| 상태 | 정상 / 경고 / 실격([인증 부정](06-abuse-risk.md#3-인증-부정)). |

### 보유 (Holding)

| 필드 | 설명 · 제약 |
|---|---|
| 참가자ID / 종목ID | 복합 키. |
| 수량 | 보유 수량. 거래 단위는 [체결 규칙](04-trading.md#2-체결-규칙-필수) 참조. |
| 평균단가 | 매수 시 갱신. 평가손익·총자산은 현재가로 파생 계산. |

### 주문 (Order)

| 필드 | 설명 · 제약 |
|---|---|
| 주문ID / 참가자ID / 종목ID | 식별. |
| 방향 | 매수 / 매도. |
| 수량 / 체결가 | 체결가 = 당일 시작가(장중 불변). |
| 접수시각 / 상태 | 09:00–18:00 접수. 접수·체결·거부 상태. |

### 가격 이력 (PriceHistory)

| 필드 | 설명 · 제약 |
|---|---|
| 종목ID / 운영일 | 복합 키. |
| 시작가 / 전일대비 변동률 | 일별 1건. F-02 시세 이력의 원천. |

### 인증 (StudyCertification)

| 필드 | 설명 · 제약 |
|---|---|
| 인증ID / 참가자ID / 대상일자 | 1인·1일 1건([인증 규칙](05-certification.md#1-인증-규칙-필수)). |
| 자료 / 이미지해시 | 업로드 자료 및 중복 검사용 해시([인증 부정](06-abuse-risk.md#3-인증-부정)). |
| 상태 / 반려사유 | 대기 / 승인 / 반려. 반려 시 사유 기록. |

### 정산 로그 (SettlementLog)

| 필드 | 설명 · 제약 |
|---|---|
| 회차 / 일자 | 1~10회차 매핑. |
| 입력 | 종목별 매수 집계, 쏠림 지수, 코인 추출 난수(p, X). |
| 출력 | 종목별 변동률, 확정 시작가. 분쟁·감사 대응(F-09). |
