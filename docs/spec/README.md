## 목적

본 문서는 공부장려 모의투자 이벤트의 시스템 구현을 위한 기능·데이터·알고리즘 규격을 정의한다. 개발과 QA는 본 문서를 구현 및 검증의 단일 기준으로 사용한다. 이벤트의 배경·동기 등 서술적 설명은 **설계 근거** 인용 블록으로 분리하며, 규격 본문에는 검증 가능한 규범 조항만 담는다.

## 범위

- **포함**: 참가자 자산 운용, 5종목(주식 4·코인 1) 가격 산정, 공부 인증·보상 지급, 일일 정산 배치, 관리자 파라미터, 어뷰징 방지.
- **제외**: 실시간 호가/체결 엔진, 실물 상품 배송·정산, 대외 결제 연동. 장중 실시간 호가는 확장 조건에서만 다룬다.

## 표기 규칙

- **규범 강도** — `필수`: 미구현 시 규격 위반 / `권장`: 정당한 사유가 없으면 따를 것 / `선택`: 구현 재량.
- **통화 단위** — 원(KRW). 모든 가격·금액은 정수 원.
- **반올림** — 별도 명시가 없으면 모든 가격은 10원 단위 반올림.
- **변동률** — 소수(예: -0.30)와 백분율(-30%)을 병기하되 계산은 소수 기준.

## 용어 정의

| 용어 | 정의 |
|---|---|
| 운영일 | 장이 열리는 하루(주말 포함). 이벤트 기간(2026-10-06 ~ 2026-10-16) 내 총 11일. |
| 가격 변동 회차 | 18:00 정산으로 산출되어 다음 운영일 시작가에 반영되는 가격 갱신 이벤트. 이벤트 기간 총 10회. |
| 시작가 | 각 운영일 09:00에 확정·공시되는 가격. 해당 운영일 장중에는 불변. |
| 시드 | 참가자에게 초기 지급되는 현금 1,000,000원. |
| 인증 보상 | 승인된 공부 인증 1건당 다음 운영일 09:00에 지급하는 현금. 기본 250,000원(시드의 1/4, v0.4). |
| 투입 원금 | 시드 + 지금까지 받은 인증 보상. 참가자마다 다르다. |
| 수익률 | (총자산 − 투입 원금) ÷ 투입 원금. 인증 보상은 손익이 아니라 원금으로 본다(v0.4). |
| 병더리움(BYUNG) | 확률적으로만 변동하는 코인 종목([03-pricing.md](03-pricing.md#1-병더리움코인-가격-산정)). |
| 초반 안정기 | 1회차부터 정해진 회차(기본 3회차)까지 병더리움 변동폭을 좁히는 기간([03-pricing.md §1.5](03-pricing.md#15-초반-안정기-v04)). |
| 기준선 | 당일 4개 주식의 집계 총매수금액 ÷ 4. |
| 쏠림 지수 rᵢ | 종목 i의 집계 매수금액이 기준선의 몇 배인지. rᵢ = 4·Bᵢ′ / B_total, 범위 [0, 4]. |
| 가상 유동성 L | 소수 참가 시 가격 왜곡을 줄이기 위해 종목별 매수금액에 더하는 상수([06-abuse-risk.md](06-abuse-risk.md)). |
