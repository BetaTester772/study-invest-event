# 거래 및 장 운영 규격

## 1. 장 운영

주문 가능 시간은 매일 09:00–18:00이며 주말에도 동일하게 장을 연다. 가격 갱신은 주식·코인 모두 1일 1회이고, 장중 시작가는 고정이다.

## 2. 체결 규칙 (필수)

- 접수 시각 09:00–18:00 밖의 주문은 거부한다.
- 체결가는 당일 시작가(장중 불변)로 하고 즉시 체결한다.
- 매수는 `현금잔고 ≥ 체결금액`, 매도는 `보유수량 ≥ 매도수량`을 검증한다.
- 1일 1종목 매수 상한 = 총자산의 40%(파라미터)를 적용한다([06-abuse-risk.md](06-abuse-risk.md#2-다중-계정)).
- 거래 단위는 미결정([08-open-questions.md](08-open-questions.md)). 권장: 주식 1주, 코인 0.0001.

## 3. 일일 정산 배치 (필수, 18:00)

아래 순서로 실행하며 결과를 다음 운영일 09:00 시작가에 반영한다.

1. 당일 종목별 매수금액 Bᵢ 집계 및 가상 유동성 L 적용.
2. 주식 변동률 산출([03-pricing.md §2](03-pricing.md#2-주식-가격-산정)) → 익일 시작가 확정.
3. 코인 확률 추출([03-pricing.md §1](03-pricing.md#1-병더리움코인-가격-산정)) → 익일 시작가 확정.
4. 가격 이력 및 정산 로그 기록(F-09).
5. 배치 실패 시: 당일 정산 무효 처리, 전일 가격 유지 후 재실행([08-open-questions.md](08-open-questions.md) 권장안).
