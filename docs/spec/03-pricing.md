# 가격 산정 규격

## 1. 병더리움(코인) 가격 산정

### 1.1 요구사항

| ID | 강도 | 요구사항 |
|---|---|---|
| SPEC-COIN-1 | 필수 | 코인 가격은 매수·매도와 무관하게 확률적으로만 변동한다. |
| SPEC-COIN-2 | 필수 | 일일 변동률 범위는 [-50%, +300%]다. |
| SPEC-COIN-3 | 필수 | 상승일 확률 ≈ 30%, 하락일 확률 ≈ 70%다. |
| SPEC-COIN-4 | 필수 | 상·하한 근처 극단값의 발생 빈도를 낮게 억제한다(분포 모양 제약). |
| SPEC-COIN-5 | 필수 | 13회 누적 결과의 중앙값이 원금 수준을 유지한다(로그 기대값 ≈ 0). |

### 1.2 알고리즘 (매 운영일 18:00, 1회)

```text
입력: 현재가 P, p_up=0.30, up_exp=3, down_exp=2, cap=+3.00, floor=-0.50

1. p ~ Uniform(0, 1)
2. X ~ Uniform(0, 1)
3. if p < p_up:                  # 상승일 (약 30%)
       r = cap   * X^up_exp      #  = +300% * X^3
   else:                         # 하락일 (약 70%)
       r = floor * X^down_exp    #  = -50%  * X^2
4. P' = round( P * (1 + r), 10원 )

출력: 새 가격 P'
```

균등난수 두 개(p, X)만 사용하므로 별도 정규분포 라이브러리가 필요하지 않다.

### 1.3 검증 기준 (파라미터 확정 시 필수 충족)

- 상승일 비율 ≈ 30%, 하락일 비율 ≈ 70%.
- 하락일 평균 ≈ -16.7%, 상승일 평균 ≈ +75%.
- 로그 기대값 E[ln(1+r)] ≈ 0 (기본 파라미터에서 ≈ -0.003).
- 13회 경로 시뮬레이션 ≥ 1,000회로 분포·순위 분산 확인(F-13).

참고 — 산술 기대값은 하루 +11%로 양수이나, 이는 드물게 발생하는 대형 상승일이 만드는 값이며 참가자 절반은 이를 경험하지 못한다.

### 1.4 분포 기준값 (참고, 기본 파라미터)

| 구간(전체 일수 기준) | 일일 변동률 | 해석 |
|---|---|---|
| 하위 5% | 약 -43% | 급락일, 13회 중 0.65회 |
| 하위 25% | 약 -21% | 하락일 |
| 중앙값(50%) | 약 -4% | 하락일이 70%이므로 중앙값은 소폭 하락 |
| 상위 30% 경계 | 0% | 이 위쪽이 상승일 구간 |
| 상위 15% | 약 +38% | 상승일의 중앙값 |
| 상위 5% | 약 +174% | 급등일, 13회 중 0.65회 |
| 상위 1% | 약 +271% | 상한 +300% 근접, 13회 중 0.13회 |

**13회 누적 배수 분포**

| 분위 | 13회 누적 배수 |
|---|---|
| 중앙값 | 약 1.0배 (원금 수준) |
| 상위 25% | 약 2.7배 |
| 상위 10% | 약 6.6배 |
| 하위 25% | 약 0.35배 |
| 하위 10% | 약 0.15배 |

**누적 상한** — 별도 누적 상한은 두지 않는다. 일일 상한 +300%로 이론상 누적은 크게 열려 있으나 실제 발생 확률은 무시할 수준이다(상위 1% 경로도 20배 미만). 표시 한계가 필요하면 [고정 상수](02-parameters.md#1-고정-상수)의 5,000,000원을 안전 상한으로 둔다(권장).

> **설계 근거** — 상승 30% / 하락 70%는 그 자체로 강한 하락 압력이다. 코인이 보유 가치가 있으려면 드문 상승일의 상승폭이 잦은 하락일의 하락폭보다 훨씬 커야 하므로(하락일 평균 -17% ↔ 상승일 평균 +70% 내외), 상한 +300%는 이 균형을 맞추기 위한 최소 여유폭이다. 상한 근처 값이 자주 나오면 이벤트가 운 한 번으로 결정되므로, 상승폭은 X³, 하락폭은 X²로 낮은 쪽에 몰리게 잡아 범위는 유지하되 극단 빈도만 눌렀다. 변동이 13회뿐이라 기대값을 0%로 고정하면 우측 꼬리가 거의 등장하지 않아 코인이 '보유할수록 손실인 벌칙 자산'이 된다. 따라서 산술 기대값이 아니라 로그 기대값(누적 중앙값)을 0으로 맞춘다.

## 2. 주식 가격 산정

### 2.1 요구사항

| ID | 강도 | 요구사항 |
|---|---|---|
| SPEC-STOCK-1 | 필수 | 주식 가격은 무작위가 아니라 당일 참가자 전체의 총매수 쏠림에 역방향으로 반응한다. |
| SPEC-STOCK-2 | 필수 | 일일 변동률 범위는 [-30%, +30%]다. |
| SPEC-STOCK-3 | 필수 | 최저가 하한 1,000원을 적용한다. |

### 2.2 정의 및 공식

```text
Bᵢ      : 종목 i 당일 매수금액
Bᵢ′     = Bᵢ + L                      # 가상 유동성 L 적용. 예시는 L=0 가정.
B_total = Σ Bᵢ′  (i = 1..4)
기준선   = B_total / 4
rᵢ      = Bᵢ′ / (B_total/4) = 4·Bᵢ′ / B_total    # rᵢ ∈ [0, 4], rᵢ=1이 기준선

변동률ᵢ = clamp( 30% × (1 − rᵢ), −30%, +30% )
새 가격  = max( 1000, round( 현재가 × (1 + 변동률ᵢ), 10원 ) )
```

기준선보다 적게 매수된 만큼 오르고 많이 매수된 만큼 내린다. rᵢ = 0(아무도 매수 안 함)에서 +30%, rᵢ = 2(기준선의 2배)에서 -30%로 상·하한에 도달한다.

### 2.3 예외 처리 (필수)

- **B_total = 0** (전 종목 매수 0): 전 종목 변동률 0%. L > 0이면 이 상황은 발생하지 않으므로 L 적용 권장.
- **특정 종목만 Bᵢ′ = 0**: rᵢ = 0 → 자동으로 +30% 적용.
- **하한**: 산출 가격이 1,000원 미만이면 1,000원으로 고정.
- **반올림**: 모든 가격은 10원 단위.

### 2.4 계산 예시 (L=0, 총매수 4,000만원 → 기준선 1,000만원)

| 종목 | 당일 매수금액 | 쏠림 지수 r | 변동률 | 반영 후 가격 |
|---|---|---|---|---|
| 삼수전자 | 2,000만원 | 2.0 | -30% | 75,000 → 52,500원 |
| SK로우닉스 | 1,200만원 | 1.2 | -6% | 170,000 → 159,800원 |
| 미래대 | 600만원 | 0.6 | +12% | 40,000 → 44,800원 |
| LB | 200만원 | 0.2 | +24% | 14,000 → 17,360원 |

> **설계 근거** — 인기 종목에 몰리면 손해가 되므로 참가자는 비인기 종목을 찾게 되고 매수가 4종목에 분산된다. 변동이 13회뿐이라 rᵢ=2에서 이미 하한에 닿도록 하락 감도를 높였고, 실제 쏠림 범위(대략 rᵢ=0.5~1.8)에서 하루 ±15~25% 변동이 나온다. 감도 조절이 필요하면 계수 30%만 파라미터로 노출한다.
