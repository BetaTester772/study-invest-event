# 가격 산정 규격

## 1. 병더리움(코인) 가격 산정

### 1.1 요구사항

| ID | 강도 | 요구사항 |
|---|---|---|
| SPEC-COIN-1 | 필수 | 코인 가격은 매수·매도와 무관하게 확률적으로만 변동한다. |
| SPEC-COIN-2 | 필수 | 일일 변동률 범위는 [-40%, +80%]다(이전 [-40%, +200%], 그 전 [-50%, +300%]. 초반 안정기 회차는 SPEC-COIN-6). |
| SPEC-COIN-3 | 필수 | 상승일 확률 ≈ 30%, 하락일 확률 ≈ 70%다. |
| SPEC-COIN-4 | 필수 | 상·하한 근처 극단값의 발생 빈도를 낮게 억제한다(분포 모양 제약). |
| SPEC-COIN-5 | 필수 | 10회 누적 결과의 중앙값이 원금 수준을 유지한다(로그 기대값 ≈ 0). |
| SPEC-COIN-6 | 필수 | 1회차부터 `coin_calm_rounds`회차(기본 3)까지는 일일 변동률 범위를 [-10%, +30%]로 좁힌다. 상승일 확률과 분포 모양(지수)은 평소와 같다(v0.4, [§1.5](#15-초반-안정기-v04)). |
| SPEC-COIN-7 | 필수 | 안정기 없이 10회 모두 평소 범위로 움직여도 누적 배수가 20배(표시 상한 5,000,000원)를 넘을 확률은 1% 미만이다(v0.4). 시뮬레이터(F-13)로 확인한다. |

### 1.2 알고리즘 (매 운영일 18:00, 1회)

```text
입력: 현재가 P, 회차 n, p_up=0.30, up_exp=2, down_exp=2, cap=+0.80, floor=-0.40,
      calm_rounds=3, calm_cap=+0.30, calm_floor=-0.10

0. if n <= calm_rounds:           # 초반 안정기 (SPEC-COIN-6)
       cap, floor = calm_cap, calm_floor
1. p ~ Uniform(0, 1)
2. X ~ Uniform(0, 1)
3. if p < p_up:                  # 상승일 (약 30%)
       r = cap   * X^up_exp      #  = +80% * X^2  (안정기 +30% * X^2)
   else:                         # 하락일 (약 70%)
       r = floor * X^down_exp    #  = -40%  * X^2  (안정기 -10% * X^2)
4. P' = round( P * (1 + r), 10원 )

출력: 새 가격 P'
```

균등난수 두 개(p, X)만 사용하므로 별도 정규분포 라이브러리가 필요하지 않다.

### 1.3 검증 기준 (파라미터 확정 시 필수 충족)

- 상승일 비율 ≈ 30%, 하락일 비율 ≈ 70%.
- 하락일 평균 ≈ -13.3%, 상승일 평균 ≈ +26.7%.
- 로그 기대값 E[ln(1+r)] ≈ 0 (기본 파라미터에서는 ≈ -0.042로 SPEC-COIN-5를 충족하지 못한다. 아래 검토 필요 참조).
- 안정기 없이 10회 누적 20배 초과 확률 < 1% (SPEC-COIN-7).
- 10회 경로 시뮬레이션 ≥ 1,000회로 분포·순위 분산 확인(F-13).

참고 — 산술 기대값은 하루 약 -1.3%로 음수다(이전 기본값 [-40%, +200%]·X³에서는 +5.7%였다). 상승일 평균(+26.7%)이 하락일 평균(-13.3%)의 두 배에 그쳐, 상승일 30%·하락일 70%에서는 상쇄되지 않는다.

> **검토 필요 (2026-10-04)** — 기본값을 상승폭 지수 2, 상한 +80%로 바꾸면서 로그 기대값이 평소 회차 기준 약 -0.042가 되어 SPEC-COIN-5(중앙값이 원금 수준 유지)를 충족하지 못한다. 10회 누적 중앙값은 안정기 포함 약 0.74배, 없이 약 0.65배다. 20배 초과 확률은 사실상 0이므로 SPEC-COIN-7은 충족한다. 중앙값을 0.88배 근처로 되돌리려면 상승 확률이나 상한을 올려야 한다(예: 상한 +200%·X³가 v0.4 값). 이 기본값이 의도한 것인지 F-13에서 확인한다.

> **이전 검토 필요 (v0.2)** — 일일 통계(상승일 30.0%, 하락일 평균 -16.7%, 상승일 평균 +74.9%, E[ln(1+r)] ≈ -0.003, 일일 분위수)는 원문과 일치한다. 그러나 누적 배수는 원문 기재값과 다르다. 중앙값은 1.0배가 아니라 약 0.88배이고, 상위 1% 경로는 20배를 넘는다. 코인 가격은 전 참가자가 공유하는 단일 경로이므로, 이벤트 전체가 5,000,000원(20배) 표시 상한에 걸릴 확률이 약 2%다. SPEC-COIN-5 충족 여부와 누적 상한 정책은 파라미터 확정(F-13) 시 다시 판단한다. v0.4에서 평소 범위를 [-40%, +200%]로 줄여 20배 초과 확률을 안정기 없이도 약 0.45%(1% 미만, SPEC-COIN-7)로 낮췄고, 초반 안정기(3회)를 포함하면 약 0.15%다. 중앙값(약 0.88배)은 그대로다.

**누적 상한** — 별도 누적 상한은 두지 않는다. 일일 상한이 +80%라 누적도 좁게 닫혀 있다(10회 기준 20배 초과 확률 0.00%, 위 검토 필요 참조). 표시 한계가 필요하면 [고정 상수](02-parameters.md#1-고정-상수)의 5,000,000원을 안전 상한으로 둔다(권장).

> **설계 근거** — 상승 30% / 하락 70%는 그 자체로 강한 하락 압력이다. 코인이 보유 가치가 있으려면 드문 상승일의 상승폭이 잦은 하락일의 하락폭보다 훨씬 커야 하므로(하락일 평균 -13% ↔ 상승일 평균 +50%), 상한은 하한과 함께 정해 로그 기대값이 0 근처가 되게 한다. v0.3까지는 [-50%, +300%]였으나, 10회 누적 20배 초과 확률(약 2%)을 1% 미만으로 낮추려고 v0.4에서 상·하한을 [-40%, +200%]로 함께 줄였다(로그 기대값 약 -0.003 → -0.004, 누적 중앙값 약 0.88배 그대로). 상한 근처 값이 자주 나오면 이벤트가 운 한 번으로 결정되므로, 상승폭은 X³, 하락폭은 X²로 낮은 쪽에 몰리게 잡아 범위는 유지하되 극단 빈도만 눌렀다. 변동이 10회뿐이라 기대값을 0%로 고정하면 우측 꼬리가 거의 등장하지 않아 코인이 '보유할수록 손실인 벌칙 자산'이 된다. 따라서 산술 기대값이 아니라 로그 기대값(누적 중앙값)을 0으로 맞춘다.

### 1.5 초반 안정기 (v0.4)

1회차부터 `coin_calm_rounds`회차(기본 3회차)까지는 상·하한만 `coin_calm_cap`(+30%)·`coin_calm_floor`(-10%)로 바꿔 추출한다. 기본 일정에서는 10/6·10/7·10/8 정산, 즉 10/7~10/9 시작가가 안정기다. 4회차(10/9 정산, 10/10 시작가)부터는 평소 범위 [-40%, +80%]로 돌아간다. 상승일 확률(30%)과 지수(X²·X²)는 그대로다.

| 항목 | 안정기 (-10% ~ +30%) | 평소 (-40% ~ +80%) |
|---|---|---|
| 상승일 비율 | 30% | 30% |
| 상승일 평균 | 약 +10.0% | 약 +26.7% |
| 하락일 평균 | 약 -3.3% | 약 -13.3% |
| 산술 평균 | 약 +0.7% | 약 -1.3% |
| 로그 기대값 E[ln(1+r)] | 약 +0.004 | 약 -0.042 |
| 하위 5% / 중앙값 / 상위 5% | 약 -8.6% / -0.8% / +20.9% | 약 -34.5% / -3.3% / +55.6% |
| 상위 1% | 약 +28.0% | 약 +74.8% |

안정기 3회를 모두 최대로 움직여도 누적 -27%(0.9³) ~ +120%(1.3³) 안이다. 값은 기본 파라미터로 경로 1,000,000회 몬테카를로(F-13) 결과이며, 관리자 시뮬레이터는 평소 회차와 안정기 회차의 일일 통계를 따로 보여 준다.

> **설계 근거 (v0.4)** — 첫날 코인을 산 참가자가 1회차 대형 상승(이전 +200%, 현행 최대 +80%) 한 번으로 크게 앞서거나 급락으로 일찍 탈락하면, 참가자가 규칙에 익숙해지고 중도 참가자가 합류하기 전에 순위가 굳는다. 그래서 초반 며칠(3~4일)은 변동폭을 좁힌다. 상·하한을 같은 비율로 줄이면(예: 둘 다 1/10) 양수인 산술 기대값은 비례해 줄지만 변동성 손실은 제곱으로 줄어 로그 기대값이 양수가 되고, 안정기 동안 코인이 오르는 쪽으로 기운다. 상한 +30%·하한 -10%는 로그 기대값을 평소와 비슷한 0 근처(약 -0.003)에 맞춘 값이라, 누적 중앙값은 거의 그대로 두고 양쪽 꼬리만 좁힌다. 안정기 길이는 `coin_calm_rounds`로 조정한다(4로 올리면 10/10 시작가까지).

## 2. 주식 가격 산정

### 2.1 요구사항

| ID | 강도 | 요구사항 |
|---|---|---|
| SPEC-STOCK-1 | 필수 | 주식 가격은 확률 모델로 움직인다. 매 정산에서 종목마다 방향(상승·하락)과 크기를 균등난수로 뽑는다. 크기는 폭 상한 × X^e(기본 e = 2)라 작은 변동이 잦고 큰 변동은 드물다. |
| SPEC-STOCK-2 | 필수 | 당일 순매수(매수 − 매도)가 클수록 오를 확률이, 순매도가 클수록 내릴 확률이 높다. 순매수가 0이면 반반이다. |
| SPEC-STOCK-3 | 필수 | 순매수든 순매도든 한쪽으로 많이 몰릴수록 변동폭의 상한(절댓값)이 작아진다. |
| SPEC-STOCK-4 | 필수 | 확률 변동률 범위는 [-30%, +30%] 안이다(폭 상한 파라미터는 30% 이하만 허용). |
| SPEC-STOCK-5 | 필수 | 최저가 하한 1,000원을 적용한다. |
| SPEC-STOCK-6 | 필수 | 다음 운영일의 호재·악재는 확률 변동률에 곱으로 얹는다. ±30%는 확률 변동률에만 적용되므로 적용률은 ±30%를 넘을 수 있다([§3](#3-호재악재)). |
| SPEC-STOCK-7 | 필수 | 뽑은 난수(u, X)와 순매수·신호·상승 확률·폭 상한은 정산 로그에 남긴다. |

### 2.2 정의 및 공식

```text
Bᵢ, Sᵢ  : 종목 i 당일 체결 매수금액, 체결 매도금액
Nᵢ      = Bᵢ − Sᵢ                                   # 순매수 (음수면 순매도)
zᵢ      = Nᵢ / ( |Nᵢ| + L )                         # 순매수 신호 ∈ (−1, 1). L: 순매수 기준(가상 유동성)
pᵢ      = 1/2 + δ · zᵢ                              # 상승 확률. δ = stock_p_shift (기본 0.3 → 0.2~0.8)
Mᵢ      = M_min + (M_max − M_min) · (1 − |zᵢ|)      # 폭 상한. M_max = 15%, M_min = 5% (기본)

uᵢ ~ U(0, 1),  Xᵢ ~ U(0, 1)
변동률ᵢ = +Mᵢ · Xᵢ^e   (uᵢ < pᵢ, 상승)            # e = stock_move_exp (기본 2)
        = −Mᵢ · Xᵢ^e   (그 밖, 하락)
적용률ᵢ = (1 + 변동률ᵢ) × (1 + 뉴스ᵢ) − 1          # 뉴스ᵢ: 다음 운영일 호재 +x / 악재 −x, 없으면 0 (§3)
새 가격  = max( 1000, round( 현재가 × (1 + 적용률ᵢ), 10원 ) )
```

하나의 신호 zᵢ가 방향과 폭을 함께 정한다. |Nᵢ| = L이면 |zᵢ| = 0.5라 상승(또는 하락) 확률 0.65, 폭 상한 10%다. 변동 크기의 평균은 폭 상한 / (e + 1)이다(기본 e = 2면 1/3). 순매수가 한없이 커지면 상승 확률은 1/2 + δ(0.8), 폭 상한은 M_min(5%)에 다가간다. 균등난수 두 개만 쓰므로 코인([§1.2](#12-알고리즘-매-운영일-1800-1회))과 같은 방식이다.

### 2.3 예외 처리 (필수)

- **순매수 0**(매매 없음, 또는 매수 = 매도): zᵢ = 0 → 상승 확률 1/2, 폭 상한 M_max. 주문이 없어도 가격은 움직인다.
- **L = 0**: zᵢ는 순매수의 부호(±1)가 되어 조금이라도 순매수가 있으면 상승 확률 1/2 + δ, 폭 상한 M_min. 소수 참가에서 한 명이 가격을 좌우하므로 L > 0을 권장한다.
- **M_min > M_max로 저장된 경우**: 둘을 정렬해 쓴다(배치가 멈추지 않게).
- **하한**: 산출 가격이 1,000원 미만이면 1,000원으로 고정.
- **반올림**: 모든 가격은 10원 단위.

### 2.4 계산 예시 (L=300만, δ=0.3, M=5%~20%, 전 종목 u=0.6·X=1)

> 계산을 보이려고 M_max = 20%(2026-10-08 이전 기본값)로 둔 예시다. X = 1이라 폭 지수 e와 무관하다.

| 종목 | 매수 B | 매도 S | 순매수 N | 신호 z | 상승 확률 | 폭 상한 | 결과 | 반영 후 가격 |
|---|---|---|---|---|---|---|---|---|
| 삼수전자 | 600만원 | 300만원 | +300만원 | +0.5 | 65% | 12.5% | u < 0.65 → +12.5% | 75,000 → 84,380원 |
| SK로우닉스 | 0 | 0 | 0 | 0 | 50% | 20% | u ≥ 0.5 → -20% | 170,000 → 136,000원 |
| 미래대 | 0 | 0 | 0 | 0 | 50% | 20% | u ≥ 0.5 → -20% | 40,000 → 32,000원 |
| LB | 100만원 | 400만원 | -300만원 | -0.5 | 35% | 12.5% | u ≥ 0.35 → -12.5% | 14,000 → 12,250원 |

같은 난수(u = 0.6)여도 순매수가 있는 삼수전자는 오르고 나머지는 내린다. 삼수전자의 상승폭(12.5%)이 매매 없는 종목의 하락폭(20%)보다 작은 것이 SPEC-STOCK-3이다.

### 2.5 분포 기준값 (기본 파라미터)

**하루, 순매수별** (해석 계산. 순매도는 상승 확률만 1 − pᵢ로 뒤집히고 폭은 같다)

| 순매수 N | 신호 z | 상승 확률 | 폭 상한 | 기대 변동률 E[r] | 로그 기대값 E[ln(1+r)] |
|---|---|---|---|---|---|
| 0 | 0 | 50.0% | 15.0% | 0% | -0.002 |
| +100만원 | +0.25 | 57.5% | 12.5% | +0.6% | +0.005 |
| +150만원 | +0.33 | 60.0% | 11.7% | +0.8% | +0.006 |
| +200만원 | +0.40 | 62.0% | 11.0% | +0.9% | +0.008 |
| +300만원 (= L) | +0.50 | 65.0% | 10.0% | +1.0% | +0.009 |
| +600만원 | +0.67 | 70.0% | 8.3% | +1.1% | +0.010 |
| +1,000만원 | +0.77 | 73.1% | 7.3% | +1.1% (최대) | +0.011 |
| +2,000만원 | +0.87 | 76.1% | 6.3% | +1.1% | +0.011 |

예상 일평균 순매수(종목당 100~200만원)는 상승 확률 57.5~62%, 폭 상한 12.5~11% 구간이다.

E[r] = (2pᵢ − 1) · Mᵢ / (e + 1) = 2δ·zᵢ·Mᵢ / (e + 1)다. 상승 확률은 순매수에 따라 계속 오르지만 폭은 줄어들므로, 기대 변동률은 순매수가 L의 2~3배일 때 +1.1% 근처에서 가장 크고 그 위로는 오히려 줄어든다. M_min = 0이면 순매수가 한없이 커질 때 기대 변동률이 0으로 간다.

**10회 누적 배수, 매일 같은 순매수** (경로 50,000회 몬테카를로, 10원 반올림 포함, 뉴스 없음, 2026-10-08)

| 매일 순매수 | 하위 10% | 하위 25% | 중앙값 | 상위 25% | 상위 10% | 1배 초과 확률 |
|---|---|---|---|---|---|---|
| 0 | 0.74배 | 0.85배 | 0.98배 | 1.13배 | 1.28배 | 46% |
| +150만원 | 0.86배 | 0.96배 | 1.07배 | 1.19배 | 1.31배 | 66% |
| -150만원 | 0.74배 | 0.82배 | 0.91배 | 1.02배 | 1.13배 | 29% |
| +600만원 | 0.96배 | 1.03배 | 1.11배 | 1.20배 | 1.28배 | 83% |

순매수가 크면 오를 가능성은 높지만 누적 수익의 위쪽 꼬리는 오히려 좁아진다(+600만원 상위 10% 1.28배 < +150만원 1.31배). (기본값 M_max = 15%·e = 2로 다시 계산, 2026-10-08.)

> **설계 근거 (2026-10-08)** — 요구는 세 가지다: 기본은 확률 모델, 살수록 오를 확률↑·팔수록 내릴 확률↑, 많이 사거나 팔수록(순매수 |N| 기준) 변동 절댓값↓. 이전 쏠림 모델(아래)은 많이 산 종목이 내리는 역방향 규칙이었고 무작위 요소는 작은 잡음뿐이었다. 새 모델에서 매수가 몰릴수록 확실히 오르기만 하면 다 같이 한 종목을 사는 것이 정답이 되므로, 몰릴수록 변동폭을 줄여 기대 이익이 일정 수준(≈ +2%) 이상 커지지 않게 했다. 몰린 종목은 "오를 가능성은 높지만 조금 오르는" 안전한 선택, 아무도 안 사는 종목은 "반반이지만 크게 움직이는" 위험한 선택이 된다. 순매도는 대칭이라 팔자가 몰리면 내릴 가능성이 높지만 폭은 작다. 방향과 폭을 하나의 신호 zᵢ로 정해 파라미터를 δ·M_max·M_min·L 네 개로 줄였다.

> **설계 근거 — 폭 상한 15%·X² (2026-10-08)** — 처음 기본값(M_max = 20%, 크기 = 폭 상한 × X)에서는 매매가 적은 종목이 매일 ±20% 안에서 고르게 움직여, 15%를 넘는 날이 종목당 약 25%였다(운영 10/9 시작가 재추첨에서 LB -16.1%). 이벤트 초반 3일(10/6~10/8)의 실제 종목별 순매수 12건을 재표본으로 쓰고, 매일 호재 1건·악재 1건(5~15%)을 곱해 시뮬레이션했다(20만 회, 누적은 남은 6회).
>
> | 크기 | M_max | 매매 없는 종목: 평균 \|Δ\| / 10% 초과 / 15% 초과 | 실제 흐름 + 뉴스: 15% 초과 / 20% 초과 | 6회 누적 5~95% (뉴스 없이) |
> |---|---|---|---|---|
> | X | 20% | 10.0% / 50% / 25% | 21% / 8.7% | -30% ~ +46% |
> | X | 15% | 7.5% / 33% / 0% | 14% / 5.2% | -24% ~ +35% |
> | X² | 20% | 6.7% / 29% / 13% | 14% / 5.0% | -24% ~ +34% |
> | **X²** | **15%** | **5.0% / 19% / 0%** | **9.7% / 3.0%** | **-19% ~ +26%** |
> | X² | 12% | 4.0% / 9% / 0% | 8.2% / 1.7% | -16% ~ +21% |
> | X² | 10% | 3.3% / 0% / 0% | 7.1% / 1.1% | -13% ~ +18% |
>
> X²·15%는 확률 변동만으로는 어떤 종목도 하루 ±15%를 넘지 않고, 15%를 넘는 날은 대부분 뉴스가 겹친 경우다. 많이 산 종목(+500만원)의 기대 변동률은 +1.1%로 매매 신호가 살아 있다. 12% 이하로 줄이면 뉴스(5~15%)가 가격을 거의 혼자 정한다. 폭 지수 e는 `stock_move_exp`로 따로 바꿀 수 있다(1이면 이전처럼 고르게).

### 2.6 이전 방식: 쏠림 모델

순매수 확률 모델을 배포하기 전 정산(이벤트 첫 회차들)은 아래 방식이었다. 그때의 정산 로그에는 `adjusted_amount`·`concentration`·`noise_factor`·`rate_factor`가 남아 있다(관리자 정산 화면은 로그 종류에 맞는 열을 보여 준다).

```text
Bᵢ′ = Bᵢ + L,  Bᵢ″ = Bᵢ′ × exp( τ·(Gᵢ − γ) )    # 매도는 집계하지 않음. Gᵢ ~ Gumbel(0,1), τ = 0.1
rᵢ  = 4·Bᵢ″ / Σ Bⱼ″                              # 쏠림 지수, 기준선(4종목 평균) = 1
변동률ᵢ = clamp( 30% × (1 − rᵢ) × kᵢ, −30%, +30% ),  kᵢ ~ U(0.9, 1.1)
```

기준선보다 많이 매수된 종목이 내리고 적게 매수된 종목이 올랐다(인기 종목 회피 → 분산 유도). 파라미터 `stock_sensitivity`(0.3)·`stock_noise_scale`(τ)·`stock_rate_jitter`(w)는 없앴으며, 저장된 파라미터에 남아 있어도 무시한다.

### 3.2 알고리즘 (전날 18:00 정산 안, 코인·주식 난수 다음, 주식 가격 산정 전)

```text
입력: 다음 운영일 D(반영일이 있어야 함), n_good=1, n_bad=1, x_min=0.05, x_max=0.15

0. D에 뉴스가 이미 있으면(관리자 작성) 끝.
후보 = 주식 4종목,  종류 목록 = [호재] × n_good + [악재] × n_bad
종류 목록의 각 종류마다 순서대로(후보가 없으면 끝):
  1. 종목 = 후보 중 균등 추출, 후보에서 뺀다(한 종목에는 하루 1건 → 호재와 악재가 같은 종목에 붙지 않는다)
  2. x = round( x_min + (x_max − x_min)·U(0,1), 0.01 )   # 하한·상한이 엇갈려 있으면 정렬해 쓴다
  3. 기사 = 종목별 기사 풀(호재 5·악재 5) + 공통 예비 풀(호재 3·악재 3, 종목명 치환) 중 이번 이벤트에서
     아직 쓰지 않은 것에서 균등 추출(다 썼으면 전체에서). 제목·부제·본문·바이라인이 함께 정해진다(§3.3).

같은 정산 → 종목별 적용률 = (1 + 확률 변동률)(1 ± x) − 1 → D 시작가 확정.  D 09:00 공시 → 가격과 뉴스(여러 건이면 한꺼번에) 함께 공개.
```

기본값이면 호재 하나와 악재 하나가 매일 서로 다른 종목에 나온다(전체 종목에서 호재 종목은 균등, 악재 종목은 남은 종목에서 균등이라 종목별 확률은 모두 같다). 이벤트 첫날은 앞선 정산이 없으므로 뉴스가 없다(관리자도 쓸 수 없다). 마지막 운영일은 반영일이 없어 뉴스를 만들지도 받지도 않는다.

### 3.3 기사 풀

무작위 뉴스는 제목 한 줄이 아니라 기사다. 종목마다 캐릭터에 맞춘 패러디 기사(삼수전자: 세 번째에 성공하는 끈기, SK로우닉스: 이름은 low인데 주가는 최고가, 미래대: 현대(現代)를 '미래'로 비튼 자동차·조선·건설 그룹, 늘 미래를 말하지만 현재는 삐걱, LB "Life is Bad": 만년 저평가와 자조 유머)를 호재 5건·악재 5건씩 두고, 어느 종목에나 쓰는 공통 예비 기사를 호재 3건·악재 3건 둔다. 공통 예비 기사는 업종이 드러나지 않는 소재(실적·특허·증권가 평가·원자재·품질)만 쓴다(가전 회사에 '서비스 장애'가 붙는 일이 없게). 기사는 제목(120자)·부제(120자)·본문 2~3문장(600자)·바이라인(가상 매체 병더리움경제TV·명륜뉴스·율전일보)으로 이루어진다. 원문은 `backend/src/study_invest/news_pool.py`에 있다.

제약: 실존 기업·인물을 거론하지 않는다(패러디 이름만). 본문에 변동률 숫자를 쓰지 않는다(크기는 §3.2에서 따로 뽑아 배지로 보인다). 호재는 명확히 긍정, 악재는 명확히 부정이다. 같은 종목에서는 이번 이벤트에 이미 나온 제목을 피한다. 관리자가 쓰는 뉴스는 부제·본문·바이라인이 선택이며, 비우면 참가자에게 제목만 보인다.

> **설계 근거 (2026-10-04)** — 주식은 참가자 전체의 쏠림에만 반응하므로 "읽고 판단할 거리"가 없다는 피드백에서 나왔다. 처음에는 아침에 발표하고 저녁 정산에 반영했으나, 악재를 보고 모두 매도하는 단순 대응이 정답이 되어 재미가 없다는 피드백으로 **발표 시점에 이미 가격에 반영**하도록 바꿨다. 뉴스는 예측 재료가 아니라 그날 가격이 왜 움직였는지 설명하는 이야기이고, 참가자의 판단은 여전히 쏠림 쪽에 있다. 효과를 쏠림 변동률에 더하지 않고 곱하는 이유는 ±30% 클램프와 독립적으로 동작시키기 위해서다. 더하면 클램프에 걸린 종목에서 뉴스가 사라진다. 코인은 분포가 따로 조정돼 있어 대상에서 뺐다. (이 근거는 쏠림 모델 때 쓴 것이다. 순매수 확률 모델에서도 뉴스는 같은 방식으로 확률 변동률에 곱한다.)
