# 시스템 개요

공부 인증을 게임 재화(병더리움 코인)와 연결한 모의투자 이벤트다. 참가자는 원화 시드로 주식 4종목과 코인 1종목을 운용하고, 공부를 인증해 코인을 추가로 획득한다. 목적은 공부 인증의 지속률을 높이는 것이며, 투자 성과는 동기부여 장치다.

## 1. 액터

- **참가자** — 자산 운용(매수·매도), 공부 인증 제출.
- **관리자** — 인증 검수, 파라미터 조정, 수동 가격 개입, 참가자 관리.
- **정산 배치(시스템)** — 18:00 가격 산정, 09:00 시작가 공시·보상 지급.
- **알림(시스템)** — 장 시작·마감·정산·인증 리마인더 푸시(선택).

## 2. 일일 운영 사이클

| 시각 | 처리 |
|---|---|
| 09:00 | 당일 시작가 확정·공시. 전일 승인된 인증분에 대한 병더리움 지급. |
| 09:00–18:00 | 매수·매도 주문 접수. 당일 시작가로 즉시 체결. |
| 18:00 | 장 마감. 정산 배치 실행: 주식 쏠림 집계·변동률 산출, 코인 확률 추출 → 다음 운영일 시작가 확정([04-trading.md](04-trading.md#3-일일-정산-배치-필수-1800)). |
| 23:59 | 공부 인증 접수 마감(파라미터). 이후 접수분은 다음 날짜 인증으로 집계. |

> **설계 근거** — 가격은 주식·코인 모두 1일 1회 갱신되며, 장중 가격은 고정이다. 따라서 참가자의 당일 매매는 '다음 운영일 가격을 함께 결정하는 행위'가 된다.
