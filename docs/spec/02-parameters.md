## 2. 관리자 조정 파라미터 (F-11)

아래 기본값은 내부 테스트(10회 경로 시뮬레이션 1,000회 이상, F-13)로 최종 확정한다.

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| 코인 상승 확률 `p_up` | 0.30 | 상승일 발생 확률. 올리면 전체가 완만해짐. |
| 코인 상승폭 지수 `up_exp` | 2 | 변동률 = +80%×X^지수. 낮추면 대형 상승이 잦아져 운 의존↑. |
| 코인 하락폭 지수 `down_exp` | 2 | 변동률 = -40%×X^지수. 소폭 하락에 몰리게 함. |
| 코인 일일 상한 `cap` | +80% | 상승일 최대 변동률(이전 +200%, 그 전 +300%). |
| 코인 일일 하한 `floor` | -40% | 하락일 최대 변동률. 상한과 함께 줄여 로그 기대값을 0 근처로 유지(v0.4, 이전 -50%). |
| 초반 안정기 회차 `coin_calm_rounds` | 3 | 1회차부터 이 회차까지 아래 안정기 상·하한을 쓴다(10/7~10/9 시작가). 0이면 안정기 없음([03 §1.5](03-pricing.md#15-초반-안정기-v04)). |
| 안정기 일일 상한 `coin_calm_cap` | +30% | 안정기 상승일 최대 변동률. |
| 안정기 일일 하한 `coin_calm_floor` | -10% | 안정기 하락일 최대 변동률. |
| 순매수 확률 폭 `stock_p_shift` | 0.3 | 상승 확률 = 1/2 + δ·zᵢ, zᵢ = Nᵢ / (\|Nᵢ\| + L). 0.3이면 0.2~0.8. 0이면 매매와 무관하게 반반, 최대 0.5([03 §2.2](03-pricing.md#22-정의-및-공식)). |
| 최대 변동폭 `stock_move_max` | 20% | 순매수 0일 때의 폭 상한 M_max. 변동률 = ±폭 상한 × X, X ~ U(0, 1). 최대 30%. |
| 최소 변동폭 `stock_move_min` | 5% | 순매수·순매도가 한없이 클 때 다가가는 폭 상한 M_min. 폭 상한 = M_min + (M_max − M_min)·(1 − \|zᵢ\|). 0~30%, M_max보다 크게 저장되면 둘을 정렬해 쓴다. |
| 가상 유동성(순매수 기준) L `virtual_liquidity` | 3,000,000원/종목 | 순매수 신호의 분모에 더한다. 예상 일평균 순매수(종목당 100~200만원)에서 신호가 0.25~0.4가 되도록 정했다. 순매수가 L이면 \|zᵢ\| = 0.5. 소수 참가 시 가격 왜곡 완화. |
| 무작위 뉴스 확률 `news_probability` | 0.5 | 정산 때 다음 운영일에 호재·악재 1건이 생길 확률. 0이면 관리자가 쓴 뉴스만([03 §3](03-pricing.md#3-호재악재)). |
| 뉴스 효과 범위 `news_rate_min`·`news_rate_max` | 10% · 20% | 무작위 뉴스의 효과 크기 x 범위(1% 단위). 호재 ×(1 + x), 악재 ×(1 − x). |
| 1일 1종목 매수 상한 | 총자산의 40% | 단독 매수 몰림·담합 제한([06-abuse-risk.md](06-abuse-risk.md)). |
| 인증 보상 `reward_cash` | 현금 250,000원 | 승인 1건당 고정 금액 지급. 시드의 1/4(v0.4, [보상 지급](05-certification.md#3-보상-지급-필수)). |
| 인증 마감 시각 | 23:59 | 이후 접수분은 익일 집계. |
