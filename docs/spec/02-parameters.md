## 2. 관리자 조정 파라미터 (F-11)

아래 기본값은 내부 테스트(10회 경로 시뮬레이션 1,000회 이상, F-13)로 최종 확정한다.

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| 코인 상승 확률 `p_up` | 0.30 | 상승일 발생 확률. 올리면 전체가 완만해짐. |
| 코인 상승폭 지수 `up_exp` | 2 | 변동률 = +80%×X^지수. 낮추면 대형 상승이 잦아져 운 의존↑. |
| 코인 하락폭 지수 `down_exp` | 2 | 변동률 = -40%×X^지수. 소폭 하락에 몰리게 함. |
| 코인 일일 상한 `cap` | +80% | 상승일 최대 변동률(이전 +200%, 그 전 +300%). |
| 코인 일일 하한 `floor` | -40% | 하락일 최대 변동률. 상한과 함께 줄여 로그 기대값을 0 근처로 유지(v0.4, 이전 -50%). |
| 초반 안정기 회차 `coin_calm_rounds` | 3 | 1회차부터 이 회차까지 아래 안정기 상·하한을 쓴다(10/7~10/9 시작가). 0이면 안정기 없음([03 §1.5](03-pricing.md#15-초반-안정기-v04)). |
| 안정기 일일 상한 `coin_calm_cap` | +30% | 안정기 상승일 최대 변동률. |
| 안정기 일일 하한 `coin_calm_floor` | -10% | 안정기 하락일 최대 변동률. |
| 주식 감도 계수 | 30% | 변동률 = 계수×(1−rᵢ), ±30% 클램프. |
| 가상 유동성 L | 5,000,000원/종목(예시) | 소수 참가 시 가격 왜곡 완화. |
| 매수지분 잡음 세기 `stock_noise_scale` | 0.1 | 종목별 매수지분에 Gumbel 잡음 배수 exp(τ·(G−γ))를 곱한다. 0이면 잡음 없음, 최대 2([03 §2.5](03-pricing.md#25-매수지분-잡음)). |
| 종목별 변동 배율 폭 `stock_rate_jitter` | 0.1 | 종목마다 배율 kᵢ ~ U(1 − w, 1 + w)를 뽑아 쏠림 변동률에 곱한 뒤 ±30%로 제한한다(기본 0.9~1.1배). 4종목 변동률의 합이 0으로 고정되지 않는다. 0이면 없음, 최대 0.5([03 §2.6](03-pricing.md#26-종목별-변동-배율)). |
| 하루 호재·악재 건수 `news_good_per_day`·`news_bad_per_day` | 1 · 1 | 정산 때 다음 운영일에 뽑는 무작위 호재·악재 건수(각 0~4, 합 4 이하). 호재와 악재는 서로 다른 종목에 붙는다. 둘 다 0이면 관리자가 쓴 뉴스만([03 §3](03-pricing.md#3-호재악재)). |
| 뉴스 효과 범위 `news_rate_min`·`news_rate_max` | 10% · 20% | 무작위 뉴스의 효과 크기 x 범위(1% 단위). 호재 ×(1 + x), 악재 ×(1 − x). |
| 1일 1종목 매수 상한 | 총자산의 40% | 단독 쏠림·담합 제한([06-abuse-risk.md](06-abuse-risk.md)). |
| 인증 보상 `reward_cash` | 현금 250,000원 | 승인 1건당 고정 금액 지급. 시드의 1/4(v0.4, [보상 지급](05-certification.md#3-보상-지급-필수)). |
