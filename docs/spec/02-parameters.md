## 2. 관리자 조정 파라미터 (F-11)

아래 기본값은 내부 테스트(10회 경로 시뮬레이션 1,000회 이상, F-13)로 최종 확정한다.

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| 코인 상승 확률 `p_up` | 0.30 | 상승일 발생 확률. 올리면 전체가 완만해짐. |
| 코인 상승폭 지수 `up_exp` | 3 | 변동률 = +300%×X^지수. 낮추면 대형 상승이 잦아져 운 의존↑. |
| 코인 하락폭 지수 `down_exp` | 2 | 변동률 = -50%×X^지수. 소폭 하락에 몰리게 함. |
| 코인 일일 상한 `cap` | +300% | 상승일 최대 변동률(요구 조건 충족 최소 여유폭). |
| 코인 일일 하한 `floor` | -50% | 하락일 최대 변동률. |
| 주식 감도 계수 | 30% | 변동률 = 계수×(1−rᵢ), ±30% 클램프. |
| 가상 유동성 L | 5,000,000원/종목(예시) | 소수 참가 시 가격 왜곡 완화. |
| 1일 1종목 매수 상한 | 총자산의 40% | 단독 쏠림·담합 제한([06-abuse-risk.md](06-abuse-risk.md)). |
| 인증 보상 가치 | 50,000원 상당(권장) | 원화 가치 고정 방식([보상 지급](05-certification.md#3-보상-지급-필수)). |
| 인증 마감 시각 | 23:59 | 이후 접수분은 익일 집계. |
