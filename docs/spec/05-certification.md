# 공부 인증 및 보상 규격

## 1. 인증 규칙 (필수)

- 공부 인증은 1인 1일 1회만 가능하다.
- 인증 자료는 공부 인증 사진 1장이다.
- 인증하지 않은 참가자도 거래는 계속할 수 있다. 해당 일의 코인 보상만 지급하지 않는다.
- 인증 접수 마감 시각(예: 당일 23:59)을 명시하고, 마감 이후 접수분은 다음 날짜 인증으로 집계한다.

## 2. 검수 (필수)

- 관리자가 승인/반려하며, 반려 시 사유를 기록한다.
- 업로드 이미지 해시 중복 검사를 병행한다([인증 부정](06-abuse-risk.md#3-인증-부정)).

## 3. 보상 지급 (필수)

승인된 인증에 대해 다음 운영일 장 시작(09:00)에 병더리움을 지급하여 참가자가 당일 장중에 즉시 운용할 수 있게 한다. 지급 방식은 **수량 고정**으로, 승인 1건당 시세와 무관하게 병더리움 `reward_coin_quantity`개(기본 1개, [파라미터](02-parameters.md#2-관리자-조정-파라미터-f-11))를 지급한다(v0.3 결정).

- 지급 코인은 매입금액 0원으로 보유에 편입한다(평균단가가 낮아지고 평가손익에 반영된다).
- 다음 운영일 09:00 이후에 승인된 인증은 그다음 운영일 09:00에 지급한다.
- 마지막 운영일 인증분은 다음 운영일이 없으므로 코인을 지급하지 않는다(인증 일수에는 포함).
- 실격 참가자에게는 지급하지 않는다.

> **설계 근거 (v0.3)** — v0.2의 원화 가치 고정(50,000원 상당)은 코인 거래 단위(정수 1단위, 시작가 250,000원)와 맞지 않아 정수 지급이 불가능했다([08](08-open-questions.md#2-결정으로-새로-생긴-미결정-항목)). 수량 고정은 시세 급등일에 보상 가치도 함께 커지는 투기성을 감수하는 대신, 보유를 정수 단위로 유지하고 규칙을 단순하게 만든다.

## 4. 개인정보 (필수)

- 인증 자료는 이벤트 종료 후 30일 이내에 삭제한다.
- 랭킹에는 닉네임만 공개한다.
